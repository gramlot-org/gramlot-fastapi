# Inspector and page experiments

[Concise counterpart](https://github.com/gramlot-org/gramlot-fastapi/blob/main/docs_llm/inspector.md).

## 1. Purpose and preview status

The inspector belongs to the shared Gramlot browser runtime. FastAPI delivers
that runtime; application developers can use it to understand and experiment with
a page's live state and UI declarations. These previews evaluate APIs and design
choices. The behavior described here is intended behavior, with bugs and incomplete
cases possible. Passing tests do not promise that all interactions work correctly.

The screenshots below come from the Django Bakery experiment. They illustrate the
shared inspector; they are not evidence of a FastAPI admin application. Their
originals are maintained in `gramlot-django/docs/_static/screenshots/`.

## 2. Open the inspector and explore Data

On a page with inspection enabled, use the magnifying-glass control or
`Ctrl+Shift+D`. Select **Data** to see the hierarchical Data Bag: the values used
by page bindings, selections, lists and other application state.

Expand a branch, select a node and inspect its value and attributes in the
Properties panel. Edit a supported value, then leave the property row to commit
the edit. Bound components should react to the change. A field without a matching
binding will not necessarily change what is visible.

![Data inspector showing an edited title and the corresponding page text](_static/screenshots/inspector-data.png)

In this Bakery example, `detail.title` was changed to `Inspector: live Data edit`.
The detail heading shows the new value. This is an illustration of Data binding,
not a database update operation.

## 3. Explore and edit Source

Select **Source** to inspect the live tree of UI declarations generated by Gramlot.
Choose a node to inspect its value and attributes. Try a supported text or visual
property to observe how the rendered component responds.

![Source inspector showing an edited heading declaration](_static/screenshots/inspector-source.png)

The example changes the heading node's value to `Explore — live Source edit`.
Source is the live declaration tree, not the original Python file. The separate
Python-source viewer in Bakery displays application code; it is not the inspector.

Inspector edits affect the current running page. They do not rewrite Python files
or automatically persist database records. Reloading or rebuilding the page can
replace them. Application controllers and bindings may also overwrite an edit or
react to it, including by invoking application services. Use disposable preview
data when experimenting; do not treat an inspector edit as an isolated save tool.

In the current FastAPI adapter a page can set `source_inspection = False` to disable
its inspector in the startup configuration. This is a presentation choice, not an
authorization boundary for server methods or database access.

## 4. Forms, validation and admin scope

Django's related experiments include a SPA administration surface, forms derived
from model information and validation. They are experimental work in the Django
integration, not features automatically supplied by choosing FastAPI as a host.

This FastAPI package hosts Python-authored Gramlot pages and Source/Data service
calls. It does not currently supply a ready-made equivalent admin application or
an ORM-driven form generator. Shared Gramlot field declarations can be used by
pages; defining model-to-form mapping, persistence and backend validation requires
an explicit database/application contract.

Client field feedback, service-argument checking, database constraints and access
control are different responsibilities. A valid-looking field in the browser does
not establish that a write is allowed or that a record has been saved. Neither the
inspector nor the Genropy adapter establishes a complete generic admin contract.

See [server/database architecture](architecture.md) and the
[database interface direction](server-and-database-integration.md) for the current
boundary. The Django experiments provide examples to evaluate, not an accepted
portable implementation promised by this adapter.
